# 开屏卫士 v7.15.10（难跳广告三类型根治：开屏×强广告形态豁免带 + 权限弹窗零扫描 + 功耗优化）

> 三图实锤根治轮：你上传的三张「难跳过」截图（CSDN 视频开屏左下圆形图片键 / 应用商店推广页纯倒计时徽章 / 上滑互动 H5「跳过 2」胶囊）与 #103 引擎日志同期——本轮逐一定位三类死洞并根治；同时按指令做整体性能与功耗优化。v7.15.9 全部能力保留。

## 三图类型的死因（VLM 解析 + 日志考古 + 代码走查）

1. **大树角落图片键死洞**：H5/视频广告的无障碍树常 300~800 节点，而角落图片键的【点击门】有 150 节点树上限——键能被收集却永远点不出去；泛位置候选（专门救「按钮位置随机」的兜底路径）收集时又排除角落几何 → **大树里的角落图片键完全无处可点**
2. **上滑互动容器死洞**：上滑互动广告（「上滑或点击」类）的容器天生可滚动，而角落/泛位点击门对可滚动窗硬挡（信息流防误点红线）——互动广告被同一条红线误伤
3. **晚到键时窗截断**：视频广告 5 秒倒计时 + 渲染延迟，跳过键可晚至 6.5 秒后才出现，而角落/泛位点击的时窗上限正是 6.5 秒
4. **系统权限弹窗白扫（#103 日志实锤）**：系统权限对话框被当成开屏扫描 + 弹窗识别双路径白扫——「开屏未命中……候选样本：拒绝/始终允许」+「弹窗未命中 · 入窗 1.79E9s」双日志刷屏。「拒绝」是全 app 误触代价最高的控件之一（拒绝权限 = 功能残废）

## 本次更新

1. **开屏×强广告形态豁免带（三图根治）**：开屏窗 × 强广告形态（全屏热区 /「广告」角标 / SDK 广告窗指纹 / 学习窗指纹）同时成立时：树上限 150→600、可滚动豁免、时窗 6.5s→8s。**误触红线全保持**：非开屏窗（信息流底部导航「我的」Tab 图标恰在角落几何带内——滚动硬挡与 150 树上限照旧）与无强广告形态窗（普通主页角落图标）一切照旧
2. **系统权限弹窗零扫描**：permissioncontroller 事件入口直接丢弃（与 systemui 同口径）——零扫描零点击零日志；权限弹窗期间前台追踪保持底层应用（弹窗关闭后无需重入判定）
3. **诊断日志升级**：未命中日志新增「图片键候选 角落N+泛位M（未出手：门控/时序）」——图片键在场但被门控挡住时直接可见（这类广告的补规则金样本）；「入窗」字段不再出现 1.79E9 疯值
4. **功耗优化**：探针去重（省电档案窗 0ms 排针与首个内容事件探针 200ms 内双跑收敛——每窗省一轮全窗枚举+文本搜索）；CLEAN 窗图形探针预算 120→180（H5 大树深层图片键复活面）；权限弹窗类系统窗零扫描。说明：能耗画像的大头是跳过手势本身（约 11µWh/次）——v7.15.9 秒跳 67 次 vs v7.15.6 42 次，多跳的每一次都是引擎在干活，本轮压缩的是纯浪费部分
5. **回归防线（双向验证）**：服务级 S8 场景（H5 大树+滚动容器+左下图片键）在旧代码上红（零出手——死洞实锤）→ 新代码绿（手势落点精确命中键区域）；S9 场景（权限弹窗）旧代码白扫 20 次 → 新代码 0 次。全套 4530 断言 + 服务级 18 项全绿
6. **发布前审核轮收口（P1）**：底部导航/Tab 栏 vid token 否决（tab/nav/bottom）——冷启动信息流首页（开屏时间窗内 + 首屏广告卡片角标激活豁免带）的「我的」类 Tab 图标绝不入候选（原生底部导航 vid 几乎必含这些 token，真跳过键不含）；负例测试补位（树Q：冷启动 feed×角标×滚动×Tab 图标 → 零出手）
