# Skip-Ad v3.14.0 · 跳过后反馈弹窗自动收起 · 秒跳再提速 · ADB 自愈移除

## 本次更新

### 1. 跳过广告后的「不喜欢/反馈」面板自动收起（issue#21）

喜马拉雅跳过开屏后 **10 次有 8 次**会弹出「不喜欢 / 反馈投诉」底部面板（重复出现 / 不喜欢此内容 / 虚假广告 / 内容不适 / 侵权违规 / 其他问题 / 我为什么会看到广告 / 取消），每次都要手动收起——本次直接解决：

- **面板出现 = 广告已关的铁证**：引擎立即停用换候选重试（issue#21 日志实锤的复验风暴 ×2~4 次元凶——面板把广告关掉了，引擎还以为没关继续点）
- **自动代点「取消」收起面板**：只点文案精确为「取消」的控件，**绝不替你提交任何反馈选项**
- 三重安全门：① 仅在引擎 12 秒内自动跳过过的应用里生效（你手动长按信息流的「不感兴趣」菜单绝不碰）；② 需 ≥1 个强特征（「我为什么会看到广告 / 反馈投诉」——信息流长按菜单没有这些词）且总特征 ≥2（双保险）；③ 预算内广度优先识别，零性能顾虑

### 2. 露头就秒再提速

- 手势被系统中断（系统限流/冲突）时：**退冷却 + 350ms 快速补扫重试**（此前要等下轮扫描，最慢 4 秒+，issue#21 日志实锤）
- 开屏「跳过」键晚渲染时补扫节流 80→50ms（前 4 秒），露头即点

### 3. ADB 自愈授权整体移除（用户反馈：要电脑执行太麻烦）

- 删除 WRITE_SECURE_SETTINGS 检查 / 自愈重绑 / 授权状态卡全部相关代码
- **开启服务只需一步**：App 内按钮直达系统无障碍开关页（Android 11+ 只剩一个开关）
- **开启一次，持续守护**：前台常驻通知 + onUnbind 保留 + 心跳自检 + 断连提醒四件套；退出 App、清理后台后重进**无需重新开启**（系统强制关闭时高优通知一键恢复，学习数据全保留）

### 4. 界面与代码瘦身

- 首页：删除 ADB 授权卡；服务状态文案改为「开启一次持续守护」
- 关于页：删除内部版本号冗余字段；最近三个版本描述**言简意赅**
- 反馈类型与代码同步清理：删除已下线的「误弹回」选项，补齐图片广告/误点击标签
- 孤儿代码清理：fuseChain / isLauncherLike 私有包装等无调用点代码删除；弹窗突发日志同包 30s 去重（issue#21：meituan 60 秒 3 条同语刷屏）
