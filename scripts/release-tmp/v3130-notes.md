### 一、验证码横幅四重防护（真机事故根治）

**事故链**：接收短信验证码时，SystemUI 顶部 heads-up 横幅弹出 → 恰逢开屏跳过键也在顶部 → 引擎手势点击屏幕坐标被横幅截走 → **验证码横幅被点掉**。

| # | 防护层 | 机制 |
| --- | --- | --- |
| ① | 覆盖层包丢弃 | 短信/彩信/来电类包（`mms` / `smsextra` / `messaging` / `incallui`）事件入口直接丢弃——绝不扫描、绝不学习（手动点「复制验证码」绝不被学成跳过键；来电界面点错 = 挂断电话） |
| ② | 文案窗口拒扫 | 树内任一节点带「验证码 / 校验码 / 动态码 / 动态密码」文案（SystemUI 横幅窗、应用内自绘提示条、银行登录页）→ 本窗口绝不扫描绝不点击 |
| ③ | 触点让路 | 手势真实触点派发前探测 SystemUI 顶部小窗（状态栏 / heads-up 横幅），触点被覆盖即拒发手势——自动降级 `performAction` 无障碍代点（不经屏幕坐标，绝不碰横幅） |
| ④ | 返回键让路 | 横幅在场时绝不派 BACK（BACK 会先关掉横幅） |

### 二、待机功耗治理（夜间不再每 5 分钟唤醒）

**根因**：v3.9.0 心跳保活用 5 分钟 `setExactAndAllowWhileIdle` 精确闹钟——**一晚把设备从 Doze 唤醒 96 次**，这是夜间待机耗电的元凶。

- **息屏休眠门**：息屏（`!PowerManager.isInteractive`）时不扫描、不点击、不学习——息屏没有可跳的广告，此时唯一可能出现在前台的是来电/闹钟等敏感窗（点击 = 误点挂断/误关闹钟）。`gestureTap` 首行息屏熔断双保险。
- **心跳自适应**：亮屏 5 分钟精确闹钟（发现快，设备本就醒着）；息屏改 **30~45 分钟窗口式非精确闹钟**（`setWindow`，系统批量调度进 Doze 维护窗，绝不唤醒设备）。

### 三、issue#16~#20 日志实锤整治

- **安全中心被学出「跳过键」**：`com.miui.securitycenter` 应用详情页被学出位置 `(91%,9%)`——下次进详情页 500ms 直点 = 在权限管理页乱点。OEM 工具包（miui / securitycenter / systemmanager / safecenter / permissionmanager / finddevice）位置学习**永久拒收** + 启动时自动清理已误学规则。
