# 开屏卫士 v7.15.6（动态图开屏泛位置识别根治 + 首页白名单精简 + 冗余清理）

> 用户实锤修复轮：Keep/CSDN 等 App 的动态图开屏广告（跳过按钮每次在不同地方、没有倒计时、纯图片）识别不到且日志里都没记录；首页白名单模块太长不美观；代码冗余清理（去除前逐项判断与测试，绝不引入不可用）。

## 本次更新

1. **泛位置图片跳过键（Keep/CSDN 动态图开屏根治）**：这类广告的跳过按钮是纯图片（无文本）、位置每次随机（含居中）、无倒计时——旧版几何带只认「顶部 14%/底部 18% + 左右缘」，居中随机位零收集 = 识别不到。本轮新增泛位置候选：
   - 任意位置（含居中）的小可点无字图键全部入候选（面积 ≤6% 屏、宽 ≤30%、高 ≤12%——比角落键更紧的尺寸门）
   - 出手门：仅强广告形态（全屏热区/广告角标/SDK 广告窗/学习窗）四选一才出手——动态图开屏的全屏可点广告图正是强信号常客；居中位无「树极简」兜底（居中误点代价比角落位高）
   - 防误点三重闸：viewId 含 download/share/user/buy 等诱导 token 一律拒收；可滚动窗绝不点；排在角落候选之后（先点像的再点不像的），复验换候选同坐标绝不重复盲刺
2. **CLEAN 档案盲区根治（「识别不到且日志没记录」头号根因）**：(pkg|cls) 连续 3 次零候选会被判省电静默（CLEAN）——之后只剩文本探针，而动态图开屏的跳过键是纯图片（无文本可探）= 不扫、不点、不记（72 小时才复查一次）。本轮新增图形探针：省电静默窗在开屏观察窗内每 1.5 秒做一次浅层树扫描（预算 120 ≈ 全量 1/5 成本），发现图片跳过键/全屏热区/广告角标任一强信号 → 档案立即复活全量出手
3. **未命中日志三重豁免 + 晚到键救回**：
   - 热区/角标在场的广告窗不再被「同包 8 秒节流」（logo 窗先记一条把真广告窗的吞掉）与「H5 大树过滤」（WebView 容器超 150 节点全吞）双杀——广告窗的未命中是补规则的黄金样本，必记录
   - 热区开屏窗 4 秒后不再全停扫：500ms 低频补扫持续到开屏观察窗截止（普通窗 12s/SDK 广告窗 20s）——晚到的跳过键（5~12s）也能救回
4. **首页白名单精简**：去掉搜索框与手动添加行；默认只显示 5 款应用（白名单内置顶）+「展开全部 N 款」按需展开（展开后仍可滚动检索全部应用）——首页更短更清爽
5. **代码冗余清理（全部经判断与测试验证，24 套件 4493 断言全绿）**：
   - 诱导词双表合一（25 词 × 2 处 → 单源引用，漂移隐患根除）
   - 低端机低电量预算降级死存储修复（此前写在主赋值前被无条件覆盖 = 白算，现真正生效）
   - 7 个孤儿桥方法 + 订阅市场死代码（约 130 行）+ 约 90 行死样式移除
   - 热区误触观察窗口径统一（SDK 广告窗 20s——v7.15.5「唯一口径」收编漏网的第四处）
   - 下载进度文本 id 错配修复（v7.3.0 遗留：进度轮询首个 tick 即 TypeError 静默死亡——进度冻结且「下载完成→立即安装」翻转永不可达）
   - 上传按钮转圈动画修复（adspin 关键帧从未定义 = spinner 一直静止）
6. **测试与验证**：JVM 24 套件 4493 断言全绿（新增 RandGraphicSkipTest 35 项——泛位置几何/vid 否决/收集门/出手门/退避联动五节）；页面资产符号闸 11 项在场通过；密钥泄露扫描全绿；ESLint 零告警；APK 签名证书与历史一致（05ada6e3…）
