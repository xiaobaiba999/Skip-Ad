# 开屏卫士 v7.15.14（后台丢功能根治）

> 用户实锤轮：「保持主功能不变的情况下继续优化，卫士挂后台长时间后容易丢失其功能作用，还要重新退出进一下，当然这是我没开启自启动状态下。日志还是经常性的不进行记录，同时开屏广告跳过的功能也丢失了。图片中的这种开屏还是跳过不了」。本轮基于 #116-#119 四台设备最新日志考古 + 四张截图 VLM 识别，根治「挂后台长时间丢功能 + 日志不记录 + 开屏不跳」同根死因（服务死透无自愈）与两处识别缺口；主功能 byte-for-byte（出手安全闸全链不变，决策核心仅新增证据信号）。v7.15.13 及之前全部能力保留。

## 死因（#116-#119 日志考古 + 截图 VLM 识别 + 代码走查）

1. **服务死透无自愈（主因——后台丢功能/日志不记录/开屏不跳三症状同根）**：#116（Xiaomi 2211133C）实锤 16:36:57 最后事件 → 21:58:31「服务已启动」**断流 3 小时 45 分**且全程「自愈/拉活 0」——死因双杀：①服务死透后的下一跳心跳闹钟是 setWindow 窗口式，App Standby 深桶/厂商省电管控（没开自启动=ROM 默认激进省电）下被推迟数小时，KeepAliveReceiver 迟迟不触发；②「保活提醒」开关关闭时 onUnbind/onTaskRemoved 直接跳过排闹钟——踢链自愈连坐被闸，服务死透后零自愈，只能靠用户「重新退出进一下」手动拉活
2. **QQ 型纯图开屏角落图片键永不出手（#119 用户实锤设备）**：mobileqq 小米营销纯图开屏——vid:mi_×2 + vid:mhh×2、无角标无热区非 SDK 窗类名、树 112 节点 > 60，L4 广告形态确认门挡死「图片键候选 角落4+泛位3（未出手：门控/时序）」三连——真跳过键就在角落候选里却永远轮不到出手
3. **百度网盘插屏整窗无指纹（#118 vivo 实锤）**：RichMediaActivity 12 分钟 16 轮「插屏未命中」——richmedia 段不在 SDK 广告窗类名表 = 零 vid-close 点击 + 零返回键兜底
4. **四张截图（喜马拉雅互动 H5×2/CSDN 图片开屏/古风视频互动）**：喜马拉雅当期战绩 50 次跳过成功、CSDN 型角落图片键链路在岗——截图时点高度吻合服务死透期（用户自述功能丢失时段），主因 1 修复后链路自动恢复

## 本次更新

1. **死透快档闹钟**：服务死透+亮屏时心跳闹钟改 setAndAllowWhileIdle +2 分钟（doze 中也准点触发，不再被 App Standby/厂商省电推迟数小时——用户正在用手机却漏拦广告的每一秒都是伤害）；服务活着 30 分钟窗口式不变；死透+息屏维持 30 分钟窗口式（夜间不耗电）。发现延迟从「小时级」降到「分钟级」
2. **keepOn 解耦（自愈不再被「保活提醒」连坐）**：闹钟链无条件排（onUnbind/onTaskRemoved 三处去闸）+ 踢链自愈无条件跑（零打扰：触发 AMS 重绑，无任何用户可见输出）——「保活提醒」开关只管通知打扰（notifyAlert 内置闸：关闭后只静默自愈、绝不弹通知）
3. **自检复活快梯**：踢链三轮终判仍死也排 +30 秒快梯（此前仅覆盖安装场景排——厂商省电管控下 AMS 重绑滞后不再干等下一档闹钟）
4. **营销 vid 证据（QQ 型根治）**：开屏窗内营销 SDK vid 前缀节点（mi_/mhh）≥2 个 = 广告容器证据，纳入 L4 角落键广告形态确认门 + 泛位键出手门 + 零候选退避联动——树 >60 无角标无热区的纯图开屏不再被挡死。双门槛收口：非开屏窗零置位、单节点不构成证据
5. **richmedia 入 SDK 广告窗表**：百度网盘 RichMediaActivity 型富媒体插屏整窗识别（vid-close + 返回兜底链路激活）
6. **回归防线**：服务级新增 S16 六项（死透快档排针/keepOn=false 闹钟不断/实例保留/解绑日志/清后台闹钟照排/息屏夜间口径不回归）——服务级 54 项全绿；核心新增 S6 营销 vid 证据十一项（QQ 树 1:1 复刻 + 单 vid 反向钉死 + 非开屏窗负例）——核心 4540 断言全绿；主功能 byte-for-byte
7. **binder 红线保持**（<50 次/秒）：死透快档 2 分钟一档 = 进程拉起 + 一次 binder 查询（踢活即回 30 分钟节奏）——红线的 1/1000 量级；营销 vid 检测为节点快照数据零 binder
