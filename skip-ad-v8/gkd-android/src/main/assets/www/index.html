快速上手
开启服务点「首页 → 开启服务」直达系统开关页。系统会显示 10 秒安全确认（防诈设计，属正常），等待后确认即可。
持续守护开启一次即可：开屏广告露头即点、软件内弹窗/插屏自动关闭，日常零操作。
免重复开启退出 App、清理后台、重启手机后都会自动恢复，无需重新开启，也无需再去系统设置。
请把卫士固定在后台（很重要）
必读
后台被清理是「息屏或切应用回来，第一条广告拦不住」的主要原因。三步加固：
1 · 最近任务加锁打开多任务界面，找到开屏卫士卡片，下拉加锁（或长按选「锁定」）——厂商清理后台不再清掉卫士。
2 · 电池白名单首页「保活体检」里有直达引导：允许卫士后台运行，省电策略不再杀服务。
3 · 通知权限允许通知——万一服务被系统关闭，通知栏会一键恢复（点按即回，全程不去系统设置）。
若卫士短暂掉线：打开卫士首页会自动恢复（也可以从通知栏一键恢复），无需任何手动设置。
常见问题
息屏或切应用回来，第一个广告没拦住？卫士后台被清理所致（见上方「固定后台」）。新版已在亮屏/解锁瞬间自动补扫，但后台被杀仍需恢复——按三步加固即可根治。
进入 App 弹出的提示是什么？开屏广告拦截提示（知道了 / 12 小时不再提示 / 去上传日志）——需强制观看 5 秒后按钮才可操作。选「12 小时不再提示」静音 12 小时，升级新版本后会再提醒一次。
检查更新失败或下载慢？检查更新失败请开启 GitHub 加速器（如 Watt Toolkit）后重试——不开梯子也能恢复；下载内置多条备用通道自动切换（CDN 直链优先），也可到 GitHub Releases 页手动下载安装。
订阅规则还要手动导入吗？不用。社区订阅每日后台自动导入（失败自动重试 + 内置快照兜底），无需任何操作。
