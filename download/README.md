## 安装 / 升级 / 卸载

- **新安装**：下载 APK → 允许「安装未知应用」→ 安装 → 首页「开启无障碍服务」
- **v3.8.1 真机自验**：① 重启手机（已 adb 授权 WRITE_SECURE_SETTINGS）→ 约 10s 后服务应自动恢复——BOOT_COMPLETED 8s 检测后由 2s 自检闹钟在全新广播窗口自愈，不再直接长轮询；② adb 手动写入短格式条目 `com.zai.adshield/.AdSkipService` 的设备自愈后 Settings 不应出现冗余双条目；③ 未授权设备重启/覆盖安装后点通知应直达服务开关（Android 11+ 一步）；④ 仍有问题：「学习中心 → 上传日志到 GitHub」一键上传（自动附设备信息），开发者据此修复
- **覆盖升级**：直接安装更高版本（同一 `adshield.keystore` 签名 + versionCode 递增），无需卸载，学习数据保留
- **应用内更新**：App 内「关于 → 检查更新」→ 页内直接下载（带进度，直连失败自动切换镜像通道）→ 一键安装；v3.3.0 起检查更新带令牌 + 重试 + 列表回退，移动网络下更稳
- **正常卸载**：系统设置 → 应用管理 → 开屏卫士 → 卸载（普通用户应用，无任何锁定机制）

`开屏卫士-源码与构建工具.zip` 为对应版本完整源码快照（含 keystore 与 build.sh）。
