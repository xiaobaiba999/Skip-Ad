     6→ * 秒跳决策核心（v3.8.0 · 纯 Java · 零 Android 依赖 · JVM 可单测）
     7→ * ─────────────────────────────────────────────────────────────
     8→ * v3.8.0 设计动机（issue#10 二轮真机反馈：喜马拉雅点击跳过键 4 次广告不关、
     9→ *  手动点立刻生效；微博找不到可点候选只能返回键，而返回键被广告拦截）——
    10→ *  网络调研 GKD（gkd-kit，同类最佳开源应用）最新全局规则与 API 文档，
    11→ *  三个方法论落地：
    12→ *  · visibleToUser 过滤：GKD 全局规则要求 [visibleToUser=true]——不可见节点
    13→ *    =陷阱/死区，点了白点（文本/vid/关闭/角落候选全部加 vis 门）；
    14→ *  · viewId 匹配：GKD 规则匹配 vid*="skip"（穿山甲 tt_splash_skip_btn /
    15→ *    微博 iv_skip 类零文本图片跳过键）和倒计时控件（vid 含 count+down
    16→ *    非 download）；
    17→ *  · clickCenter 方法论：「跳过」文案+大容器可点祖先时，标签自身坐标仍是
    18→ *    有效触点——手势直点即可（performAction 大容器=点开广告，绝不走）。
    19→ *  配套改造：假跳过手势候选梯子（L1 统一轮换）、walk 内候选排序（自身可点/
    20→ *  短文案/小面积优先）、角落键前置到 SDK 直断之前（CLS_BREAK_MS 500→700：
    21→ *  点击优先直断兜底）、跳过文案倒计时解析 parseCountdown。
    22→ * v3.7.0 设计动机（四次真机反馈 issue#10：喜马拉雅「已点击跳过×4」仍不关，
    23→ *  手动点同一按钮立刻生效；微博陀螺仪窗返回键直断无效果——广告拦截返回键）：
    24→ *  · 喜马拉雅根因链：① 无障碍服务缺 canPerformGestures → 手势真实触点
    25→ *    从未真正触达屏幕（服务侧配置修复）；② 手势路径单点零长度 → 部分
    26→ *    ROM 不触发点击（服务侧路径修复）；③ 决策层只点第一个「跳过」文本
    27→ *    候选，复验重试点同一坐标 4 遍——广告图内常嵌假「跳过」文本，
    28→ *    首选候选可能是陷阱/死区。对策（本类）：多候选收集 + 第 N 次点击
    29→ *    换第 N 个候选（skipCands）；学习位置（用户手指真正点通过的位置）
    30→ *    前置到 L1 之前——教过就优先直点，不再盲点文本候选。
    31→ *  · 微博根因链：L3 陀螺仪文案 120ms 就返回键直断，抢在角落键点击
    32→ *    （500ms）之前；返回键被广告 Activity 拦截后扫描链熔断，无复验无
    33→ *    兜底。对策：L3 降级到 L4 之后（有可点候选先点击，点完/无候选才
    34→ *    返回键）；返回键直断后由服务侧 600ms 复验（不熔断）。
    35→ *  · 角落键/关闭键受简单树 40 节点上限误伤（广告窗树常大）：放宽为
    36→ *    CORNER_TREE_MAX_NODES=150（热区直断/坐标兜底仍保持严格）。
    37→ *
    38→ * v3.6.0 设计动机（三次真机反馈：喜马拉雅二次进入被引擎连按两次返回键
    39→ *  「模拟人操作退出」到桌面——v3.5.0 的返回键兜底在第一方开屏窗=退出应用）：
    40→ *  · 返回键只在「返回后仍在应用内」的窗口上安全：SDK 广告窗（独立广告
    41→ *    Activity，下面是应用主页）与应用内窗（主页之上拉起的广告页）。
    42→ *    应用入口窗（rootWindow：冷启动开屏/从后台回前台首窗）上按返回
    43→ *    = 退出应用（喜马拉雅拦截返回弹「再按一次退出」，第二次直接退出）。
    44→ *  · 对策：根窗口禁一切返回键兜底（L3/L4.5/L5），只走点击梯子（文本→
    45→ *    学习位置→×关闭键→角落候选→三位置坐标轮换），用尽优雅收手。
    46→ *
    47→ * v3.5.0 设计动机（二次真机反馈：日志显示「已点击跳过」但广告纹丝不动，
    48→ *  手动点两次也没学下来——微博/喜马拉雅还是得手动关）：
    49→ *  · v3.4.0 点击后立即熔断扫描链，从不复验：performAction 返回 true 但被
    50→ *    应用拦截、手势点偏、按钮尚未可点——点了等于白点，且无第二次机会。
    51→ *  · 手动点击学习只认「跳过/关闭」文本：图片跳过键零文本 → 永远学不到。
    52→ *  · v3.5.0 对策（本类决策阶梯，全部可单测）：
    53→ *    L1   文本跳过键（含 contentDescription）→ 代点（performAction 失效改手势）
    54→ *    L1.5 【新】学习位置点击：手动点过的位置指纹（归一化坐标+窗口类名），
    55→ *         次启同窗 500ms 直点——图片跳过键「教一次就会」
    56→ *    L1.6 【新】开屏×关闭键：顶部小关闭键 + 广告形态树 → 代点
    57→ *         （v3.4.0 发现了关闭键却在开屏窗内从不点它）
    58→ *    L2   SDK/学习 className 窗口指纹 → 返回键直断（500ms / 学习指纹 300ms）
    59→ *    L3 无倒计时翻转/摇一摇文案 → 120ms 立即直断；带倒计时(假跳过) → 800ms 直断
    60→ *    L4   角落无字小可点控件（多候选）：第 N 次复验换第 N 个候选点，
    61→ *         而不是同一个错位置点三遍；v3.6.0 改纯手势点击子控件坐标
    62→ *         （performAction 可能落到大热区祖先=点开广告本体）
    63→ *    L4.5 点击复验失败升级：同一广告窗内点击 ≥3 次仍未关闭 →
    64→ *         返回键兜底【仅应用内窗】（v3.6.0 根窗口豁免，见下）
    65→ *    L5 全屏热区（自绘图片广告三条件）→ 900ms 返回键直断（守护名单豁免）
    66→ *    L6 开屏窗坐标级点击兜底：简单树(无滚动/无输入框/节点少)且无任何
    67→ *        信号 → dispatchGesture 点击标准跳过位，v3.6.0 三位置轮换：
    68→ *         右上(88%,7%) → 右下(90%,92%) → 左上(8%,7%)，第 N 次点第 N 个，
    69→ *         守护名单豁免（防误点；长文本豁免）
    70→ *    P  弹窗窗期：角标强信号 / Dialog+≥2营销话术弱信号 → 代点关闭
    71→ *  · v3.6.0 根窗口返回键安全门（三次真机反馈：喜马拉雅二次进入被
    72→ *    「模拟人操作退出」——引擎在第一方开屏窗用返回键兜底，喜马拉雅拦截
    73→ *    返回键弹「再按一次退出到桌面」，引擎再按 → 真退到桌面）：
    74→ *    rootWindow=应用入口窗（从前台其他应用/桌面切来的首个窗口）时，
    75→ *    返回键=退出应用，L3/L4.5/L5 全部禁用；仅 SDK 广告窗（独立广告
    76→ *    Activity，返回回到应用内页）豁免。根窗口只走点击梯子，用尽即收手。
    77→ *  · 决策输出与执行分离：本类只产出 Decision（动作+坐标+原因），
    78→ *    服务侧负责 performAction / dispatchGesture / GLOBAL_ACTION_BACK，
    79→ *    以及点击后的复验调度（扫描链不熔断，窗未变即换候选/真实触点重试）。
    80→ */

   264→    public static ScanFind walk(NodeView root, Ctx ctx) {
   265→        ScanFind f = new ScanFind();
   266→        if (root == null) return f;
   267→        String rootCls = nz(root.cls()).toLowerCase();
   268→        f.dialogForm = rootCls.contains("dialog") || rootCls.contains("popup");
   269→        int[] budget = {ctx.budgetNodes};
   270→        visit(root, 0, budget, f, ctx);
   271→        // v3.8.0 候选排序：真键优先——① 自身可点（无祖先中转）② 文案更短（精确「跳过」
   272→        // 优先于「5s后可跳过」类长文案）③ 面积更小。防「第 1 候选是广告图内假文本」
   273→        try {
   274→            java.util.Collections.sort(f.skipCands, (a, b) -> {
   275→                if (a.selfClick != b.selfClick) return a.selfClick ? -1 : 1;
   276→                int la = a.label == null ? 0 : a.label.length();
   277→                int lb = b.label == null ? 0 : b.label.length();
   278→                if (la != lb) return la - lb;
   279→                return Double.compare(areaRatio(a.tapBounds, ctx), areaRatio(b.tapBounds, ctx));
   280→            });
   281→        } catch (Throwable ignored) {
   282→        }
   283→        return f;
   284→    }

   286→    private static void visit(NodeView node, int depth, int[] budget, ScanFind f, Ctx ctx) {
   287→        if (node == null || depth > 32 || budget[0] <= 0) return;
   288→        budget[0]--;
   289→        f.nodeCount++;
   290→        try {
   291→            String text = nz(node.text());
   292→            String desc = nz(node.desc());
   293→            String label = text.length() > 0 ? text : desc;
   294→            String cls = nz(node.cls()).toLowerCase();
   295→            boolean vis = node.visible();
   296→            if (label.length() > LONG_TEXT_LEN) f.longText = true; // 长文本=正常内容页（v3.5.0）
   297→            if (node.editable() || cls.contains("edittext")) f.editPresent = true;
   298→            if (node.scrollable() || cls.contains("scrollview") || cls.contains("recyclerview")
   299→                    || cls.contains("viewpager") || cls.contains("listview")) f.scrollPresent = true;
   300→
   301→            int[] b = node.bounds();
   302→            boolean clickable = node.clickable();
   303→            double areaRatio = areaRatio(b, ctx);
   304→
   305→            // 全屏热区：可点且 ≥55% 屏幕
   306→            if (!f.hotZone && clickable && areaRatio >= HOT_ZONE_AREA) f.hotZone = true;
   307→
   308→            if (label.length() > 0) {
   309→                if (label.length() <= 14 && matchesSkip(label)) {
   310→                    int cd = parseCountdown(label);
   311→                    if (cd > f.countdownN) f.countdownN = cd; // v3.8.0 倒计时解析（「跳过 3」→3，服务侧门控用）
   312→                    NodeView click = resolveClickable(node, 4);
   313→                    if (click != null && isSmallClick(click, ctx) && vis) {
   314→                        if (!f.foundSkip) {
   315→                            f.foundSkip = true;
   316→                            f.skipNode = click;
   317→                            // v3.6.0：手势点击用【原标签控件】坐标（点得准），
   318→                            // 不再用可点祖先中心（祖先常是全屏容器，点中心=点开广告，
   319→                            // 真机「已点击跳过但广告纹丝不动」根因之一）；performAction 仍走祖先
   320→                            f.skipBounds = (b != null && areaRatio(b, ctx) < SKIP_AREA_MAX) ? b : click.bounds();
   321→                            f.skipLabel = label;
   322→                        }
   323→                        // v3.7.0 多候选收集：广告图内常嵌假「跳过」文本（或同窗多个跳过键），
   324→                        // 复验第 N 次点第 N 个候选——不再同一坐标点四遍（issue#10 根因）
   325→                        if (f.skipCands.size() < SKIP_CANDS_MAX) {
   326→                            SkipCand c = new SkipCand();
   327→                            c.clickNode = click;
   328→                            c.tapBounds = (b != null && areaRatio(b, ctx) < SKIP_AREA_MAX) ? b : click.bounds();
   329→                            c.label = label;
   330→                            c.selfClick = (click == node);
   331→                            f.skipCands.add(c);
   332→                        }
   333→                    } else {
   334→                        f.fakeSkip = true; // 大面积/不可点 = 图内假跳过陷阱
   335→                        // v3.8.0：假跳过≠不可点——大容器可点祖先吞掉 performAction 时，
   336→                        // 标签自身坐标仍是有效触点（GKD clickCenter 方法论）：手势点标签
   337→                        // 位置，由应用按坐标分发到真跳过键。仅收角落形态小标签（防中央诱饵）
   338→                        if (vis && b != null && areaRatio(b, ctx) < FAKE_TAP_AREA_MAX
   339→                                && learnableSkipShape(b, ctx.screenW, ctx.screenH)
   340→                                && f.fakeCands.size() < SKIP_CANDS_MAX) {
   341→                            SkipCand c = new SkipCand();
   342→                            c.clickNode = click;
   343→                            c.tapBounds = b;
   344→                            c.label = label;
   345→                            c.gestureOnly = true;
   346→                            f.fakeCands.add(c);
   347→                        }
   348→                    }
   349→                } else if (label.length() <= 22 && matchesAny(label, GYRO_HINTS)) {
   350→                    f.gyroHint = true;
   351→                } else if (label.length() <= 6 && isCloseText(label)) {
   352→                    NodeView click = resolveClickable(node, 4);
   353→                    if (click != null && isSmallClick(click, ctx) && vis && !f.foundClose) {
   354→                        f.foundClose = true;
   355→                        f.closeNode = click;
   356→                        // v3.6.0：同 L1——手势点原标签坐标，performAction 走可点祖先
   357→                        f.closeBounds = (b != null && areaRatio(b, ctx) < SKIP_AREA_MAX) ? b : click.bounds();
   358→                        f.closeLabel = label;
   359→                    }
   360→                } else if (isAdBadge(label)) {
   361→                    f.adBadge = true;
   362→                    f.badgeLabel = label;
   363→                } else if (label.length() <= 14 && matchesAny(label, CTA_TEXTS)) {
   364→                    f.ctaCount++;
   365→                }
   366→            } else if (b != null && vis && node.childCount() == 0 && isVidSkip(node)) {
   367→                // v3.8.0：viewId 跳过键（GKD 全局规则同款）：vid 含 skip（穿山甲 tt_splash_skip_btn /
   368→                // 微博 iv_skip 类零文本图片键）或倒计时控件（count+down 非 download）——
   369→                // 零文本图片跳过键的头号信号，此前只能靠角落形态猜，猜不中就只能返回键
   370→                NodeView click = resolveClickable(node, 4);
   371→                if (click != null && isSmallClick(click, ctx)) {
   372→                    if (!f.foundSkip) {
   373→                        f.foundSkip = true;
   374→                        f.skipNode = click;
   375→                        f.skipBounds = b;
   376→                        f.skipLabel = "跳过";
   377→                    }
   378→                    if (f.skipCands.size() < SKIP_CANDS_MAX) {
   379→                        SkipCand c = new SkipCand();
   380→                        c.clickNode = click;
   381→                        c.tapBounds = b;
   382→                        c.label = "跳过";
   383→                        c.selfClick = (click == node);
   384→                        f.skipCands.add(c);
   385→                    }
   386→                } else if (areaRatio(b, ctx) < FAKE_TAP_AREA_MAX
   387→                        && learnableSkipShape(b, ctx.screenW, ctx.screenH)
   388→                        && f.fakeCands.size() < SKIP_CANDS_MAX) {
   389→                    SkipCand c = new SkipCand();
   390→                    c.clickNode = click;
   391→                    c.tapBounds = b;
   392→                    c.label = "跳过";
   393→                    c.gestureOnly = true;
   394→                    f.fakeCands.add(c);
   395→                }
   396→                int cd = parseCountdown(node.viewId());
   397→                if (cd > f.countdownN) f.countdownN = cd;
   398→            } else if (b != null && vis && f.corners.size() < MAX_CORNERS && isCornerControl(b, ctx)
   399→                    && !hasCornerChild(node, ctx)) {
   400→                // 【v3.5.0】角落无字小可点控件（多候选）：疑似图片跳过键
   401→                // （微博/喜马拉雅第一方开屏）；自身不可点时向上找可点祖先；
   402→                // 若还有更小的角落子控件则让位（子控件坐标点得更准）
   403→                NodeView click = clickable ? node : resolveClickable(node, 4);
   404→                if (click != null) {
   405→                    CornerCand c = new CornerCand();
   406→                    c.clickNode = click;
   407→                    c.tapBounds = b;
   408→                    f.corners.add(c);
   409→                }
   410→            }
   411→
   412→            int n = node.childCount();
   413→            for (int i = 0; i < n; i++) {
   414→                visit(node.child(i), depth + 1, budget, f, ctx);
   415→            }
   416→        } catch (Throwable ignored) {
   417→        }
   418→    }

   420→    /** 顶部区域判定（开屏×关闭键防误点：真广告×在顶部，隐私/业务弹窗按钮在底部） */
   421→    static boolean inTopArea(int[] b, Ctx ctx) {
   422→        if (b == null || ctx.screenH <= 0) return false;
   423→        int cy = (b[1] + b[3]) / 2;
   424→        return cy <= ctx.screenH * CLOSE_TOP_MAX;
   425→    }
   426→
   427→    /** 是否存在更小的角落子控件（有则父容器让位：子控件坐标点得更准） */
   428→    static boolean hasCornerChild(NodeView node, Ctx ctx) {
   429→        int n = node.childCount();
   430→        for (int i = 0; i < n; i++) {
   431→            NodeView c = node.child(i);
   432→            if (c == null) continue;
   433→            if (nz(c.text()).length() > 0 || nz(c.desc()).length() > 0) continue;
   434→            int[] cb = c.bounds();
   435→            if (cb != null && isCornerControl(cb, ctx)) return true;
   436→        }
   437→        return false;
   438→    }
   439→
   440→    /** 角落控件判定：顶部 14% 高内、贴右缘(≥72%)或左缘(≤28%)、边长 24px~35% 宽、无任何文本 */
   441→    static boolean isCornerControl(int[] b, Ctx ctx) {
   442→        if (b == null || ctx.screenW <= 0 || ctx.screenH <= 0) return false;
   443→        int w = b[2] - b[0];
   444→        int h = b[3] - b[1];
   445→        if (w < CORNER_MIN_PX || h < CORNER_MIN_PX) return false;
   446→        if (w > ctx.screenW * 0.35 || h > ctx.screenH * 0.20) return false;
   447→        if (b[1] > ctx.screenH * CORNER_TOP_MAX) return false;
   448→        boolean rightEdge = b[2] >= ctx.screenW * CORNER_RIGHT_MIN;
   449→        boolean leftEdge = b[0] <= ctx.screenW * CORNER_LEFT_MAX;
   450→        return rightEdge || leftEdge;
   451→    }

   453→    /** 向上找可点击祖先（最多 4 层） */
   454→    static NodeView resolveClickable(NodeView node, int maxUp) {
   455→        NodeView cur = node;
   456→        for (int i = 0; i < maxUp && cur != null; i++) {
   457→            if (cur.clickable()) return cur;
   458→            cur = cur.parent();
   459→        }
   460→        return null;
   461→    }
   462→
   463→    static boolean isSmallClick(NodeView n, Ctx ctx) {
   464→        if (n == null || !n.clickable()) return false;
   465→        int[] b = n.bounds();
   466→        if (ctx.screenW <= 0 || b == null) return true; // 无屏幕信息时放宽
   467→        double ratio = areaRatio(b, ctx);
   468→        int w = b[2] - b[0];
   469→        return ratio < SKIP_AREA_MAX && w < ctx.screenW * SKIP_WIDTH_MAX;
   470→    }
   471→
   472→    static double areaRatio(int[] b, Ctx ctx) {
   473→        if (b == null || ctx.screenW <= 0 || ctx.screenH <= 0) return 0;
   474→        double area = (double) (b[2] - b[0]) * (b[3] - b[1]);
   475→        return area / ((double) ctx.screenW * ctx.screenH);
   476→    }

   488→    /** 是否角落形态控件（服务侧手动点击位置学习用） */
   489→    public static boolean cornerLike(int[] b, int screenW, int screenH) {
   490→        Ctx c = new Ctx();

   492→        c.screenH = screenH;
   493→        return isCornerControl(b, c);
   494→    }

   496→    /**
   497→     * v3.6.0 学习形状判定（比扫描用的 isCornerControl 更宽）：
   498→     * 手动点击教学时，跳过键可能是——
   499→     *  · 顶部 25% 区域内的小控件（最常见：右上「跳过」图片键）；
   500→     *  · 底部 20% 区域内的小控件（部分应用跳过键在右下角，真机反馈）；
   501→     *  · 标准角落形态（顶部 14% + 贴左/右缘）。
   502→     * 面积上限由调用方按 POS_LEARN_AREA_MAX 校验（大热区=CTA，不学）。
   503→     */
   504→    public static boolean learnableSkipShape(int[] b, int screenW, int screenH) {
   505→        if (b == null || screenW <= 0 || screenH <= 0) return false;
   506→        if (cornerLike(b, screenW, screenH)) return true;
   507→        int cy = (b[1] + b[3]) / 2;
   508→        boolean topArea = cy <= screenH * 0.25;
   509→        boolean bottomArea = cy >= screenH * 0.80;
   510→        boolean small = (b[2] - b[0]) <= screenW * 0.5 && (b[3] - b[1]) <= screenH * 0.15;
   511→        return (topArea || bottomArea) && small;
   512→    }

   514→    /** v3.7.0：学习位置健全性校验——归一化坐标必须在屏内有效区（3%~97%）。
   515→     *  真机日志实锤：微信学出 (63%,102%) 越界位置（点击事件源节点 bounds
   516→     *  中心在屏幕外），点了也是死区——此类直接拒学，防止污染规则库 */
   517→    public static boolean saneNormPos(double x, double y) {
   518→        return x >= POS_MIN_NORM && x <= POS_MAX_NORM
   519→                && y >= POS_MIN_NORM && y <= POS_MAX_NORM;
   520→    }

   522→    /* ═════════ 决策阶梯 ═════════ */
   523→
   524→    public static Decision decide(ScanFind f, Ctx ctx) {
   525→        /* ── 开屏/插屏窗内 ── */
   526→        if (ctx.splashLive) {
   527→            /* v3.7.0 学习位置【前置】到 L1 之前（issue#10 根因）：
   528→             * 用户手动点通过的位置 = 真实手指触点真正生效的坐标——比盲点
   529→             * 文本候选可靠得多（文本候选可能是广告图内假「跳过」文本）。
   530→             * 教过一次，下次同窗优先直点这个位置。 */
   531→            // L1.4 学习位置点击（v3.7.0 前置）：手动点过的位置指纹 → 次启同窗 500ms 直点
   532→            //     安全门：仅在广告形态窗（简单树/SDK 窗/学习窗）内出手，
   533→            //     信息流等正常界面（可滚动/有输入框/节点多）绝不点
   534→            if (ctx.tapHintX >= 0 && ctx.tapHintY >= 0 && ctx.clickAttempts == 0
   535→                    && ctx.elapsedMs >= LEARNED_POS_MS
   536→                    && (isAdLike(f) || ctx.sdkAdWin || ctx.learnedCls)) {
   537→                Decision d = new Decision();
   538→                d.action = A_TAP_POINT;
   539→                d.x = ctx.tapHintX;
   540→                d.y = ctx.tapHintY;
   541→                d.reason = "learned_pos";
   542→                return d;
   543→            }
   544→            /* L1 文本/vid 跳过键多候选轮换（真候选 → 假跳过手势候选统一梯子）
   545→             * v3.8.0（issue#10 二轮·GKD 方法论对齐）：
   546→             *  · 新增假跳过手势候选——「跳过」文案+大容器可点祖先（微博实锤：isSmallClick
   547→             *    判假→从不点击只返回键，返回键又被广告拦截）→ 手势直点标签自身坐标
   548→             *    （clickCenter），performAction 大容器=点开广告绝不走；
   549→             *  · walk 内候选排序：自身可点/短文案/小面积优先，真键排前 */
   550→            int R = f.skipCands.size();
   551→            int F = f.fakeCands.size();
   552→            if (R + F > 0) {
   553→                int idx = Math.min(ctx.clickAttempts, R + F - 1);
   554→                if (idx < R) {
   555→                    SkipCand c = f.skipCands.get(idx);
   556→                    return click(c.clickNode, c.tapBounds, "skip_text");
   557→                }
   558→                SkipCand c = f.fakeCands.get(idx - R);
   559→                return click(null, c.tapBounds, "fake_skip_tap"); // 手势专用：大容器祖先不 performAction
   560→            }
   561→            // L1.6 开屏×关闭键（v3.5.0）：顶部小关闭键 + 广告形态树（非长文本内容页）
   562→            //     v3.7.0 树上限放宽（CORNER_TREE_MAX_NODES）：广告窗树常大，
   563→            //     40 节点上限把真关闭键挡在门外（微博根因之一）
   564→            if (f.foundClose && f.closeBounds != null && !f.longText
   565→                    && (isAdLikeLoose(f) || ctx.sdkAdWin || ctx.learnedCls)
   566→                    && inTopArea(f.closeBounds, ctx)
   567→                    && ctx.elapsedMs >= SPLASH_CLOSE_MS) {
   568→                return click(f.closeNode, f.closeBounds, "splash_close");
   569→            }
   570→            // L4 角落无字小可点控件（图片跳过键，多候选）→ 手势点击其中心
   571→            //     v3.5.0：复验失败换下一个候选（第 N 次点击用第 N 个候选点）
   572→            //     v3.6.0：改纯手势（node=null）——performAction 可能落到大热区
   573→            //     祖先（=点开广告本体）；手势点子控件坐标=真实手指点跳过键
   574→            //     v3.7.0：① 前置到 L3 之前（微博根因：陀螺仪文案 120ms 抢先
   575→            //     返回键，角落键 500ms 才轮到——有点击候选先点击，点不到再断）；
   576→            //     ② 树上限放宽 CORNER_TREE_MAX_NODES=150（广告窗树常大）
   577→            //     v3.8.0：前置到 L2 直断之前——角落键 500ms 时机先于 700ms 直断，
   578→            //     有可点目标绝不先按返回键
   579→            if (!f.corners.isEmpty() && ctx.clickAttempts < f.corners.size()
   580→                    && !f.scrollPresent && !f.editPresent
   581→                    && f.nodeCount <= CORNER_TREE_MAX_NODES
   582→                    && ctx.elapsedMs >= CORNER_MIN_MS && ctx.elapsedMs <= CORNER_MAX_MS) {
   583→                CornerCand c = f.corners.get(ctx.clickAttempts);
   584→                return click(null, c.tapBounds, "corner_image_skip");
   585→            }
   586→            // L2 SDK / 学习 className 窗口指纹 → 返回键直断
   587→            //    SDK 广告窗是独立 Activity，返回回到应用内页——根窗口也安全。
   588→            //    v3.6.0 学习指纹快断加双保险（真机事故：毒指纹把主页学成广告窗
   589→            //    → 入口窗快断=按返回键退出应用）：① 仅非根窗口或 SDK 窗可快断；
   590→            //    ② 须为广告形态树（信息流等可滚动页面绝不快断）
   591→            boolean sdkCut = ctx.sdkAdWin && ctx.elapsedMs >= CLS_BREAK_MS;
   592→            boolean learnedCut = ctx.learnedCls && ctx.elapsedMs >= CLS_LEARNED_BREAK_MS
   593→                    && (!ctx.rootWindow || ctx.sdkAdWin) && isAdLike(f);
   594→            if (sdkCut || learnedCut) {
   595→                return back(learnedCut && !sdkCut ? "sdk_window_learned" : "sdk_window");
   596→            }
   597→            /* v3.6.0 根窗口返回键安全门 ─────────────────────────────
   598→             * 应用入口窗（冷启动开屏/回前台首窗）上按返回键 = 退出应用。
   599→             * 真机事故（喜马拉雅）：v3.5.0 返回键兜底 → 喜马拉雅拦截返回
   600→             * 弹「再按一次退出到桌面」→ 引擎 600ms 后再按 → 真退到桌面，
   601→             * 用户「第二次进入就被模拟人操作退出来」。
   602→             * 此后 L3/L4.5/L5 的返回键决策仅在应用内窗（返回回到应用内）
   603→             * 或 SDK 广告窗上生效；根窗口只走点击梯子，用尽优雅收手。 */
   604→            boolean backSafe = !ctx.rootWindow || ctx.sdkAdWin;
   605→            // L3 陀螺仪/假跳过：无倒计时立即直断；带倒计时(假跳过) 800ms 直断
   606→            //     v3.6.0 加信息流安全门：可滚动/有输入框的页面出现「摇一摇/翻转」文案
   607→            //     多为互动玩法或 feed 内容（如「摇一摇抽签」），绝不返回键（防主页误退）
   608→            //     v3.7.0 移到 L4 之后（微博根因）：有可点候选先点击，返回键是
   609→            //     「无任何可点目标」时的兜底（广告 Activity 常拦截返回键）；
   610→            //     gyro_immediate 加「无可点候选」门——角落键 500ms 才到时机，
   611→            //     有候选时等它，不 120ms 抢跑返回键
   612→            boolean clickableCand = !f.corners.isEmpty() || !f.skipCands.isEmpty() || !f.fakeCands.isEmpty() || f.foundClose;
   613→            if (backSafe && f.gyroHint && !f.fakeSkip && !clickableCand
   614→                    && !f.scrollPresent && !f.editPresent
   615→                    && ctx.elapsedMs >= GYRO_IMMEDIATE_MS) {
   616→                return back("gyro_immediate");
   617→            }
   618→            if (backSafe && (f.gyroHint || f.fakeSkip) && !f.scrollPresent && !f.editPresent
   619→                    && ctx.elapsedMs >= GYRO_BREAK_MS) {
   620→                return back("gyro_break");
   621→            }
   622→            // L4.5 点击复验失败升级（v3.5.0）：同窗点击 ≥3 次仍未关闭 → 返回键兜底
   623→            //     v3.6.0：仅应用内窗（返回回到应用内）；根窗口绝不返回键（防退出）
   624→            if (ctx.clickAttempts >= CLICK_VERIFY_MAX && backSafe && isAdLike(f)
   625→                    && ctx.elapsedMs >= GYRO_BREAK_MS) {
   626→                return back("click_verify_fail");
   627→            }
   628→            // L5 全屏热区（自绘图片广告）→ 返回键直断（守护名单豁免；v3.6.0 根窗口豁免）
   629→            if (f.hotZone && backSafe && !ctx.guard && !f.editPresent && f.nodeCount <= HOT_ZONE_MAX_NODES
   630→                    && ctx.elapsedMs >= HOT_ZONE_MS) {
   631→                return back("hot_zone");
   632→            }
   633→            // L6 坐标级点击兜底：开屏窗内简单树且无信号 → 点标准跳过位
   634→            //    v3.6.0 三位置轮换：右上(88%,7%) → 右下(90%,92%) → 左上(8%,7%)，
   635→            //    第 N 次兜底点第 N 个（角落候选用尽后接续计数），三个用尽即收手
   636→            //    v3.7.0 树上限放宽（isAdLikeLoose）：广告窗树常大，零信号也能兜底
   637→            int coordIdx = f.corners.isEmpty() ? ctx.clickAttempts
   638→                    : ctx.clickAttempts - f.corners.size();
   639→            if (coordIdx >= 0 && coordIdx < COORD_XS.length && isAdLikeLoose(f) && !f.longText
   640→                    && !ctx.guard && ctx.elapsedMs >= COORD_TAP_MS
   641→                    && ctx.elapsedMs <= COORD_TAP_MAX_MS) {
   642→                Decision d = new Decision();
   643→                d.action = A_TAP_POINT;
   644→                d.x = (int) (ctx.screenW * COORD_XS[coordIdx]);
   645→                d.y = (int) (ctx.screenH * COORD_YS[coordIdx]);
   646→                d.reason = "coord_fallback";
   647→                return d;
   648→            }
   649→        }
   650→
   651→        /* ── 弹窗窗期（独立于开屏窗） ── */
   652→        if (ctx.popupLive && f.foundClose && f.closeBounds != null) {
   653→            boolean strong = f.adBadge;                    // 角标强信号
   654→            boolean weak = f.dialogForm && f.ctaCount >= 2; // Dialog + ≥2 营销话术
   655→            if (strong || weak) {
   656→                Decision d = click(f.closeNode, f.closeBounds, strong ? "popup_badge" : "popup_cta");
   657→                d.action = A_CLOSE;
   658→                return d;
   659→            }
   660→        }
   661→
   662→        return Decision.none();
   663→    }

   666→    static boolean isAdLike(ScanFind f) {
   667→        if (f.scrollPresent || f.editPresent) return false;
   668→        return f.hotZone || f.nodeCount <= AD_LIKE_MAX_NODES;

   672→     *  （微博真机：>40 节点把真角落键挡在门外），只要无滚动/无输入框且
   673→     *  节点 ≤150 即认可；热区直断/学习指纹快断仍用严格版 isAdLike 防误判 */
   674→    static boolean isAdLikeLoose(ScanFind f) {

   702→                || c.contains("baidu.mobads") || c.contains("csjad") || c.contains("unionad")) return true;
   703→        String[] seg = c.split("[.$]");
   704→        for (String s : seg) {

   707→            if (s.contains("openadsdk") || s.contains("adsdk") || s.contains("kwad")

   711→                    || s.contains("splashad") || s.contains("adsplash") || s.contains("landingpage")
   712→                    || s.contains("adpage") || s.contains("adlanding")) return true;
   713→        }
   714→        return false;
   715→    }

   733→    /** v3.8.0：viewId 跳过键判定（GKD 全局规则 -1 同款）：vid 含 skip（大小写不敏感，
   734→     *  穿山甲 tt_splash_skip_btn / 微博 iv_skip 类），或倒计时控件（含 count 与 down 且非 download） */
   735→    static boolean isVidSkip(NodeView node) {

   737→        if (vid == null || vid.length() < 4) return false;
   738→        String v = vid.toLowerCase();
   739→        if (v.contains("skip")) return true;
   740→        return v.contains("count") && v.contains("down") && !v.contains("download");
   741→    }

   743→    /** v3.8.0：解析跳过文案中的倒计时秒数（「跳过 3」「3s后可跳过」「跳过广告 5」→ 3/3/5）。
   744→     *  穿山甲类 SDK 倒计时结束前跳过键不响应点击（点了白点还占冷却）——服务侧据此
   745→     *  门控到「倒计时将尽」再出手，出手即命中。无倒计时返回 0。 */
   746→    public static int parseCountdown(String label) {
   747→        if (label == null) return 0;
   748→        for (int i = 0; i < label.length(); i++) {
   749→            char ch = label.charAt(i);
   750→            if (ch >= '1' && ch <= '9') {
   751→                int v = ch - '0';
   752→                if (i + 1 < label.length()) {
   753→                    char nx = label.charAt(i + 1);
   754→                    if (nx >= '0' && nx <= '9') v = v * 10 + (nx - '0');
   755→                }
   756→                return (v >= 1 && v <= COUNTDOWN_MAX_S) ? v : 0;
   757→            }
   758→            if (ch == '0') return 0; // 「0元领」类营销数字非倒计时
   759→        }
   760→        return 0;
   761→    }

   780→    public static boolean isAdBadge(String label) {
   781→        if (label == null) return false;
   782→        String t = label.trim();
   783→        String lower = t.toLowerCase();
   784→        if (t.equals("广告") || t.equals("推广") || t.equals("赞助") || t.equals("广告推广")) return true;
   785→        if (lower.equals("ad") || lower.equals("sponsored") || lower.equals("promoted")) return true;
   786→        return t.length() <= 8 && (t.startsWith("广告 ") || t.startsWith("广告·") || t.endsWith(" 广告"));
   787→    }
