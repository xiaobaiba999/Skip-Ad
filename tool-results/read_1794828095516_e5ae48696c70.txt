     6→ * 秒跳决策核心（v3.7.0 · 纯 Java · 零 Android 依赖 · JVM 可单测）
     7→ * ─────────────────────────────────────────────────────────────
     8→ * v3.7.0 设计动机（四次真机反馈 issue#10：喜马拉雅「已点击跳过×4」仍不关，
     9→ *  手动点同一按钮立刻生效；微博陀螺仪窗返回键直断无效果——广告拦截返回键）：
    10→ *  · 喜马拉雅根因链：① 无障碍服务缺 canPerformGestures → 手势真实触点
    11→ *    从未真正触达屏幕（服务侧配置修复）；② 手势路径单点零长度 → 部分
    12→ *    ROM 不触发点击（服务侧路径修复）；③ 决策层只点第一个「跳过」文本
    13→ *    候选，复验重试点同一坐标 4 遍——广告图内常嵌假「跳过」文本，
    14→ *    首选候选可能是陷阱/死区。对策（本类）：多候选收集 + 第 N 次点击
    15→ *    换第 N 个候选（skipCands）；学习位置（用户手指真正点通过的位置）
    16→ *    前置到 L1 之前——教过就优先直点，不再盲点文本候选。
    17→ *  · 微博根因链：L3 陀螺仪文案 120ms 就返回键直断，抢在角落键点击
    18→ *    （500ms）之前；返回键被广告 Activity 拦截后扫描链熔断，无复验无
    19→ *    兜底。对策：L3 降级到 L4 之后（有可点候选先点击，点完/无候选才
    20→ *    返回键）；返回键直断后由服务侧 600ms 复验（不熔断）。
    21→ *  · 角落键/关闭键受简单树 40 节点上限误伤（广告窗树常大）：放宽为
    22→ *    CORNER_TREE_MAX_NODES=150（热区直断/坐标兜底仍保持严格）。
    23→ *
    24→ * v3.6.0 设计动机（三次真机反馈：喜马拉雅二次进入被引擎连按两次返回键
    25→ *  「模拟人操作退出」到桌面——v3.5.0 的返回键兜底在第一方开屏窗=退出应用）：
    26→ *  · 返回键只在「返回后仍在应用内」的窗口上安全：SDK 广告窗（独立广告
    27→ *    Activity，下面是应用主页）与应用内窗（主页之上拉起的广告页）。
    28→ *    应用入口窗（rootWindow：冷启动开屏/从后台回前台首窗）上按返回
    29→ *    = 退出应用（喜马拉雅拦截返回弹「再按一次退出」，第二次直接退出）。
    30→ *  · 对策：根窗口禁一切返回键兜底（L3/L4.5/L5），只走点击梯子（文本→
    31→ *    学习位置→×关闭键→角落候选→三位置坐标轮换），用尽优雅收手。
    32→ *
    33→ * v3.5.0 设计动机（二次真机反馈：日志显示「已点击跳过」但广告纹丝不动，
    34→ *  手动点两次也没学下来——微博/喜马拉雅还是得手动关）：
    35→ *  · v3.4.0 点击后立即熔断扫描链，从不复验：performAction 返回 true 但被
    36→ *    应用拦截、手势点偏、按钮尚未可点——点了等于白点，且无第二次机会。
    37→ *  · 手动点击学习只认「跳过/关闭」文本：图片跳过键零文本 → 永远学不到。
    38→ *  · v3.5.0 对策（本类决策阶梯，全部可单测）：
    39→ *    L1   文本跳过键（含 contentDescription）→ 代点（performAction 失效改手势）
    40→ *    L1.5 【新】学习位置点击：手动点过的位置指纹（归一化坐标+窗口类名），
    41→ *         次启同窗 500ms 直点——图片跳过键「教一次就会」
    42→ *    L1.6 【新】开屏×关闭键：顶部小关闭键 + 广告形态树 → 代点
    43→ *         （v3.4.0 发现了关闭键却在开屏窗内从不点它）
    44→ *    L2   SDK/学习 className 窗口指纹 → 返回键直断（500ms / 学习指纹 300ms）
    45→ *    L3 无倒计时翻转/摇一摇文案 → 120ms 立即直断；带倒计时(假跳过) → 800ms 直断
    46→ *    L4   角落无字小可点控件（多候选）：第 N 次复验换第 N 个候选点，
    47→ *         而不是同一个错位置点三遍；v3.6.0 改纯手势点击子控件坐标
    48→ *         （performAction 可能落到大热区祖先=点开广告本体）
    49→ *    L4.5 点击复验失败升级：同一广告窗内点击 ≥3 次仍未关闭 →
    50→ *         返回键兜底【仅应用内窗】（v3.6.0 根窗口豁免，见下）
    51→ *    L5 全屏热区（自绘图片广告三条件）→ 900ms 返回键直断（守护名单豁免）
    52→ *    L6 开屏窗坐标级点击兜底：简单树(无滚动/无输入框/节点少)且无任何
    53→ *        信号 → dispatchGesture 点击标准跳过位，v3.6.0 三位置轮换：
    54→ *         右上(88%,7%) → 右下(90%,92%) → 左上(8%,7%)，第 N 次点第 N 个，
    55→ *         守护名单豁免（防误点；长文本豁免）
    56→ *    P  弹窗窗期：角标强信号 / Dialog+≥2营销话术弱信号 → 代点关闭
    57→ *  · v3.6.0 根窗口返回键安全门（三次真机反馈：喜马拉雅二次进入被
    58→ *    「模拟人操作退出」——引擎在第一方开屏窗用返回键兜底，喜马拉雅拦截
    59→ *    返回键弹「再按一次退出到桌面」，引擎再按 → 真退到桌面）：

   235→    /* ═════════ 控件树遍历（多信号一次收集） ═════════ */
   236→
   237→    public static ScanFind walk(NodeView root, Ctx ctx) {
   238→        ScanFind f = new ScanFind();
   239→        if (root == null) return f;
   240→        String rootCls = nz(root.cls()).toLowerCase();
   241→        f.dialogForm = rootCls.contains("dialog") || rootCls.contains("popup");
   242→        int[] budget = {ctx.budgetNodes};
   243→        visit(root, 0, budget, f, ctx);
   244→        return f;
   245→    }
   246→
   247→    private static void visit(NodeView node, int depth, int[] budget, ScanFind f, Ctx ctx) {
   248→        if (node == null || depth > 32 || budget[0] <= 0) return;
   249→        budget[0]--;
   250→        f.nodeCount++;
   251→        try {
   252→            String text = nz(node.text());
   253→            String desc = nz(node.desc());
   254→            String label = text.length() > 0 ? text : desc;
   255→            String cls = nz(node.cls()).toLowerCase();
   256→            if (label.length() > LONG_TEXT_LEN) f.longText = true; // 长文本=正常内容页（v3.5.0）
   257→            if (node.editable() || cls.contains("edittext")) f.editPresent = true;
   258→            if (node.scrollable() || cls.contains("scrollview") || cls.contains("recyclerview")
   259→                    || cls.contains("viewpager") || cls.contains("listview")) f.scrollPresent = true;
   260→
   261→            int[] b = node.bounds();
   262→            boolean clickable = node.clickable();
   263→            double areaRatio = areaRatio(b, ctx);
   264→
   265→            // 全屏热区：可点且 ≥55% 屏幕
   266→            if (!f.hotZone && clickable && areaRatio >= HOT_ZONE_AREA) f.hotZone = true;
   267→
   268→            if (label.length() > 0) {
   269→                if (label.length() <= 14 && matchesSkip(label)) {
   270→                    NodeView click = resolveClickable(node, 4);
   271→                    if (click != null && isSmallClick(click, ctx)) {
   272→                        if (!f.foundSkip) {
   273→                            f.foundSkip = true;
   274→                            f.skipNode = click;
   275→                            // v3.6.0：手势点击用【原标签控件】坐标（点得准），
   276→                            // 不再用可点祖先中心（祖先常是全屏容器，点中心=点开广告，
   277→                            // 真机「已点击跳过但广告纹丝不动」根因之一）；performAction 仍走祖先
   278→                            f.skipBounds = (b != null && areaRatio(b, ctx) < SKIP_AREA_MAX) ? b : click.bounds();
   279→                            f.skipLabel = label;
   280→                        }
   281→                        // v3.7.0 多候选收集：广告图内常嵌假「跳过」文本（或同窗多个跳过键），
   282→                        // 复验第 N 次点第 N 个候选——不再同一坐标点四遍（issue#10 根因）
   283→                        if (f.skipCands.size() < SKIP_CANDS_MAX) {
   284→                            SkipCand c = new SkipCand();
   285→                            c.clickNode = click;
   286→                            c.tapBounds = (b != null && areaRatio(b, ctx) < SKIP_AREA_MAX) ? b : click.bounds();
   287→                            c.label = label;
   288→                            f.skipCands.add(c);
   289→                        }
   290→                    } else {
   291→                        f.fakeSkip = true; // 大面积/不可点 = 图内假跳过陷阱
   292→                    }
   293→                } else if (label.length() <= 22 && matchesAny(label, GYRO_HINTS)) {
   294→                    f.gyroHint = true;
   295→                } else if (label.length() <= 6 && isCloseText(label)) {
   296→                    NodeView click = resolveClickable(node, 4);
   297→                    if (click != null && isSmallClick(click, ctx) && !f.foundClose) {
   298→                        f.foundClose = true;
   299→                        f.closeNode = click;
   300→                        // v3.6.0：同 L1——手势点原标签坐标，performAction 走可点祖先
   301→                        f.closeBounds = (b != null && areaRatio(b, ctx) < SKIP_AREA_MAX) ? b : click.bounds();
   302→                        f.closeLabel = label;
   303→                    }
   304→                } else if (isAdBadge(label)) {
   305→                    f.adBadge = true;
   306→                    f.badgeLabel = label;
   307→                } else if (label.length() <= 14 && matchesAny(label, CTA_TEXTS)) {
   308→                    f.ctaCount++;
   309→                }
   310→            } else if (b != null && f.corners.size() < MAX_CORNERS && isCornerControl(b, ctx)
   311→                    && !hasCornerChild(node, ctx)) {
   312→                // 【v3.5.0】角落无字小可点控件（多候选）：疑似图片跳过键
   313→                // （微博/喜马拉雅第一方开屏）；自身不可点时向上找可点祖先；
   314→                // 若还有更小的角落子控件则让位（子控件坐标点得更准）
   315→                NodeView click = clickable ? node : resolveClickable(node, 4);
   316→                if (click != null) {
   317→                    CornerCand c = new CornerCand();
   318→                    c.clickNode = click;
   319→                    c.tapBounds = b;
   320→                    f.corners.add(c);
   321→                }
   322→            }
   323→
   324→            int n = node.childCount();
   325→            for (int i = 0; i < n; i++) {
   326→                visit(node.child(i), depth + 1, budget, f, ctx);
   327→            }
   328→        } catch (Throwable ignored) {
   329→        }
   330→    }

   332→    /** 顶部区域判定（开屏×关闭键防误点：真广告×在顶部，隐私/业务弹窗按钮在底部） */
   333→    static boolean inTopArea(int[] b, Ctx ctx) {
   334→        if (b == null || ctx.screenH <= 0) return false;
   335→        int cy = (b[1] + b[3]) / 2;
   336→        return cy <= ctx.screenH * CLOSE_TOP_MAX;
   337→    }

   339→    /** 是否存在更小的角落子控件（有则父容器让位：子控件坐标点得更准） */
   340→    static boolean hasCornerChild(NodeView node, Ctx ctx) {
   341→        int n = node.childCount();
   342→        for (int i = 0; i < n; i++) {
   343→            NodeView c = node.child(i);
   344→            if (c == null) continue;
   345→            if (nz(c.text()).length() > 0 || nz(c.desc()).length() > 0) continue;
   346→            int[] cb = c.bounds();
   347→            if (cb != null && isCornerControl(cb, ctx)) return true;
   348→        }
   349→        return false;
   350→    }

   352→    /** 角落控件判定：顶部 14% 高内、贴右缘(≥72%)或左缘(≤28%)、边长 24px~35% 宽、无任何文本 */
   353→    static boolean isCornerControl(int[] b, Ctx ctx) {
   354→        if (b == null || ctx.screenW <= 0 || ctx.screenH <= 0) return false;
   355→        int w = b[2] - b[0];
   356→        int h = b[3] - b[1];
   357→        if (w < CORNER_MIN_PX || h < CORNER_MIN_PX) return false;
   358→        if (w > ctx.screenW * 0.35 || h > ctx.screenH * 0.20) return false;
   359→        if (b[1] > ctx.screenH * CORNER_TOP_MAX) return false;
   360→        boolean rightEdge = b[2] >= ctx.screenW * CORNER_RIGHT_MIN;
   361→        boolean leftEdge = b[0] <= ctx.screenW * CORNER_LEFT_MAX;
   362→        return rightEdge || leftEdge;
   363→    }

   365→    /** 向上找可点击祖先（最多 4 层） */
   366→    static NodeView resolveClickable(NodeView node, int maxUp) {
   367→        NodeView cur = node;
   368→        for (int i = 0; i < maxUp && cur != null; i++) {
   369→            if (cur.clickable()) return cur;
   370→            cur = cur.parent();
   371→        }
   372→        return null;
   373→    }

   375→    static boolean isSmallClick(NodeView n, Ctx ctx) {
   376→        if (n == null || !n.clickable()) return false;
   377→        int[] b = n.bounds();
   378→        if (ctx.screenW <= 0 || b == null) return true; // 无屏幕信息时放宽
   379→        double ratio = areaRatio(b, ctx);
   380→        int w = b[2] - b[0];
   381→        return ratio < SKIP_AREA_MAX && w < ctx.screenW * SKIP_WIDTH_MAX;
   382→    }

   384→    static double areaRatio(int[] b, Ctx ctx) {
   385→        if (b == null || ctx.screenW <= 0 || ctx.screenH <= 0) return 0;
   386→        double area = (double) (b[2] - b[0]) * (b[3] - b[1]);
   387→        return area / ((double) ctx.screenW * ctx.screenH);
   388→    }

   408→    /**
   409→     * v3.6.0 学习形状判定（比扫描用的 isCornerControl 更宽）：
   410→     * 手动点击教学时，跳过键可能是——
   411→     *  · 顶部 25% 区域内的小控件（最常见：右上「跳过」图片键）；
   412→     *  · 底部 20% 区域内的小控件（部分应用跳过键在右下角，真机反馈）；
   413→     *  · 标准角落形态（顶部 14% + 贴左/右缘）。
   414→     * 面积上限由调用方按 POS_LEARN_AREA_MAX 校验（大热区=CTA，不学）。
   415→     */
   416→    public static boolean learnableSkipShape(int[] b, int screenW, int screenH) {
   417→        if (b == null || screenW <= 0 || screenH <= 0) return false;
   418→        if (cornerLike(b, screenW, screenH)) return true;
   419→        int cy = (b[1] + b[3]) / 2;
   420→        boolean topArea = cy <= screenH * 0.25;
   421→        boolean bottomArea = cy >= screenH * 0.80;
   422→        boolean small = (b[2] - b[0]) <= screenW * 0.5 && (b[3] - b[1]) <= screenH * 0.15;
   423→        return (topArea || bottomArea) && small;
   424→    }

   428→     *  中心在屏幕外），点了也是死区——此类直接拒学，防止污染规则库 */
   429→    public static boolean saneNormPos(double x, double y) {
   430→        return x >= POS_MIN_NORM && x <= POS_MAX_NORM
   431→                && y >= POS_MIN_NORM && y <= POS_MAX_NORM;
   432→    }

   434→    /* ═════════ 决策阶梯 ═════════ */
   435→
   436→    public static Decision decide(ScanFind f, Ctx ctx) {
   437→        /* ── 开屏/插屏窗内 ── */
   438→        if (ctx.splashLive) {
   439→            /* v3.7.0 学习位置【前置】到 L1 之前（issue#10 根因）：
   440→             * 用户手动点通过的位置 = 真实手指触点真正生效的坐标——比盲点
   441→             * 文本候选可靠得多（文本候选可能是广告图内假「跳过」文本）。
   442→             * 教过一次，下次同窗优先直点这个位置。 */
   443→            // L1.4 学习位置点击（v3.7.0 前置）：手动点过的位置指纹 → 次启同窗 500ms 直点
   444→            //     安全门：仅在广告形态窗（简单树/SDK 窗/学习窗）内出手，
   445→            //     信息流等正常界面（可滚动/有输入框/节点多）绝不点
   446→            if (ctx.tapHintX >= 0 && ctx.tapHintY >= 0 && ctx.clickAttempts == 0
   447→                    && ctx.elapsedMs >= LEARNED_POS_MS
   448→                    && (isAdLike(f) || ctx.sdkAdWin || ctx.learnedCls)) {
   449→                Decision d = new Decision();
   450→                d.action = A_TAP_POINT;
   451→                d.x = ctx.tapHintX;
   452→                d.y = ctx.tapHintY;
   453→                d.reason = "learned_pos";
   454→                return d;
   455→            }
   456→            // L1 文本跳过键（文本或 contentDescription）→ 代点
   457→            //     v3.7.0 多候选轮换：第 N 次出手点第 N 个候选（广告图内常嵌
   458→            //     假「跳过」文本，首选可能是陷阱/死区——不再同一坐标点四遍）
   459→            if (f.foundSkip && !f.skipCands.isEmpty()) {
   460→                int idx = Math.min(ctx.clickAttempts, f.skipCands.size() - 1);
   461→                SkipCand c = f.skipCands.get(idx);
   462→                return click(c.clickNode, c.tapBounds, "skip_text");
   463→            }
   464→            if (f.foundSkip && f.skipBounds != null) {
   465→                return click(f.skipNode, f.skipBounds, "skip_text");
   466→            }
   467→            // L1.6 开屏×关闭键（v3.5.0）：顶部小关闭键 + 广告形态树（非长文本内容页）
   468→            //     v3.7.0 树上限放宽（CORNER_TREE_MAX_NODES）：广告窗树常大，
   469→            //     40 节点上限把真关闭键挡在门外（微博根因之一）
   470→            if (f.foundClose && f.closeBounds != null && !f.longText
   471→                    && (isAdLikeLoose(f) || ctx.sdkAdWin || ctx.learnedCls)
   472→                    && inTopArea(f.closeBounds, ctx)
   473→                    && ctx.elapsedMs >= SPLASH_CLOSE_MS) {
   474→                return click(f.closeNode, f.closeBounds, "splash_close");
   475→            }
   476→            // L2 SDK / 学习 className 窗口指纹 → 返回键直断
   477→            //    SDK 广告窗是独立 Activity，返回回到应用内页——根窗口也安全。
   478→            //    v3.6.0 学习指纹快断加双保险（真机事故：毒指纹把主页学成广告窗
   479→            //    → 入口窗快断=按返回键退出应用）：① 仅非根窗口或 SDK 窗可快断；
   480→            //    ② 须为广告形态树（信息流等可滚动页面绝不快断）
   481→            boolean sdkCut = ctx.sdkAdWin && ctx.elapsedMs >= CLS_BREAK_MS;
   482→            boolean learnedCut = ctx.learnedCls && ctx.elapsedMs >= CLS_LEARNED_BREAK_MS
   483→                    && (!ctx.rootWindow || ctx.sdkAdWin) && isAdLike(f);
   484→            if (sdkCut || learnedCut) {
   485→                return back(learnedCut && !sdkCut ? "sdk_window_learned" : "sdk_window");
   486→            }
   487→            /* v3.6.0 根窗口返回键安全门 ─────────────────────────────
   488→             * 应用入口窗（冷启动开屏/回前台首窗）上按返回键 = 退出应用。
   489→             * 真机事故（喜马拉雅）：v3.5.0 返回键兜底 → 喜马拉雅拦截返回
   490→             * 弹「再按一次退出到桌面」→ 引擎 600ms 后再按 → 真退到桌面，
   491→             * 用户「第二次进入就被模拟人操作退出来」。
   492→             * 此后 L3/L4.5/L5 的返回键决策仅在应用内窗（返回回到应用内）
   493→             * 或 SDK 广告窗上生效；根窗口只走点击梯子，用尽优雅收手。 */
   494→            boolean backSafe = !ctx.rootWindow || ctx.sdkAdWin;
   495→            // L4 角落无字小可点控件（图片跳过键，多候选）→ 手势点击其中心
   496→            //     v3.5.0：复验失败换下一个候选（第 N 次点击用第 N 个候选点）
   497→            //     v3.6.0：改纯手势（node=null）——performAction 可能落到大热区
   498→            //     祖先（=点开广告本体）；手势点子控件坐标=真实手指点跳过键
   499→            //     v3.7.0：① 前置到 L3 之前（微博根因：陀螺仪文案 120ms 抢先
   500→            //     返回键，角落键 500ms 才轮到——有点击候选先点击，点不到再断）；
   501→            //     ② 树上限放宽 CORNER_TREE_MAX_NODES=150（广告窗树常大）
   502→            if (!f.corners.isEmpty() && ctx.clickAttempts < f.corners.size()
   503→                    && !f.scrollPresent && !f.editPresent
   504→                    && f.nodeCount <= CORNER_TREE_MAX_NODES
   505→                    && ctx.elapsedMs >= CORNER_MIN_MS && ctx.elapsedMs <= CORNER_MAX_MS) {
   506→                CornerCand c = f.corners.get(ctx.clickAttempts);
   507→                return click(null, c.tapBounds, "corner_image_skip");
   508→            }
   509→            // L3 陀螺仪/假跳过：无倒计时立即直断；带倒计时(假跳过) 800ms 直断
   510→            //     v3.6.0 加信息流安全门：可滚动/有输入框的页面出现「摇一摇/翻转」文案
   511→            //     多为互动玩法或 feed 内容（如「摇一摇抽签」），绝不返回键（防主页误退）
   512→            //     v3.7.0 移到 L4 之后（微博根因）：有可点候选先点击，返回键是
   513→            //     「无任何可点目标」时的兜底（广告 Activity 常拦截返回键）；
   514→            //     gyro_immediate 加「无可点候选」门——角落键 500ms 才到时机，
   515→            //     有候选时等它，不 120ms 抢跑返回键
   516→            boolean clickableCand = !f.corners.isEmpty() || f.foundSkip || f.foundClose;
   517→            if (backSafe && f.gyroHint && !f.fakeSkip && !clickableCand
   518→                    && !f.scrollPresent && !f.editPresent
   519→                    && ctx.elapsedMs >= GYRO_IMMEDIATE_MS) {
   520→                return back("gyro_immediate");
   521→            }
   522→            if (backSafe && (f.gyroHint || f.fakeSkip) && !f.scrollPresent && !f.editPresent
   523→                    && ctx.elapsedMs >= GYRO_BREAK_MS) {
   524→                return back("gyro_break");
   525→            }
   526→            // L4.5 点击复验失败升级（v3.5.0）：同窗点击 ≥3 次仍未关闭 → 返回键兜底
   527→            //     v3.6.0：仅应用内窗（返回回到应用内）；根窗口绝不返回键（防退出）
   528→            if (ctx.clickAttempts >= CLICK_VERIFY_MAX && backSafe && isAdLike(f)
   529→                    && ctx.elapsedMs >= GYRO_BREAK_MS) {
   530→                return back("click_verify_fail");
   531→            }
   532→            // L5 全屏热区（自绘图片广告）→ 返回键直断（守护名单豁免；v3.6.0 根窗口豁免）
   533→            if (f.hotZone && backSafe && !ctx.guard && !f.editPresent && f.nodeCount <= HOT_ZONE_MAX_NODES
   534→                    && ctx.elapsedMs >= HOT_ZONE_MS) {
   535→                return back("hot_zone");
   536→            }
   537→            // L6 坐标级点击兜底：开屏窗内简单树且无信号 → 点标准跳过位
   538→            //    v3.6.0 三位置轮换：右上(88%,7%) → 右下(90%,92%) → 左上(8%,7%)，
   539→            //    第 N 次兜底点第 N 个（角落候选用尽后接续计数），三个用尽即收手
   540→            //    v3.7.0 树上限放宽（isAdLikeLoose）：广告窗树常大，零信号也能兜底
   541→            int coordIdx = f.corners.isEmpty() ? ctx.clickAttempts
   542→                    : ctx.clickAttempts - f.corners.size();
   543→            if (coordIdx >= 0 && coordIdx < COORD_XS.length && isAdLikeLoose(f) && !f.longText
   544→                    && !ctx.guard && ctx.elapsedMs >= COORD_TAP_MS
   545→                    && ctx.elapsedMs <= COORD_TAP_MAX_MS) {
   546→                Decision d = new Decision();
   547→                d.action = A_TAP_POINT;
   548→                d.x = (int) (ctx.screenW * COORD_XS[coordIdx]);
   549→                d.y = (int) (ctx.screenH * COORD_YS[coordIdx]);
   550→                d.reason = "coord_fallback";
   551→                return d;
   552→            }
   553→        }
   554→
   555→        /* ── 弹窗窗期（独立于开屏窗） ── */
   556→        if (ctx.popupLive && f.foundClose && f.closeBounds != null) {
   557→            boolean strong = f.adBadge;                    // 角标强信号
   558→            boolean weak = f.dialogForm && f.ctaCount >= 2; // Dialog + ≥2 营销话术
   559→            if (strong || weak) {
   560→                Decision d = click(f.closeNode, f.closeBounds, strong ? "popup_badge" : "popup_cta");
   561→                d.action = A_CLOSE;
   562→                return d;
   563→            }
   564→        }
   565→
   566→        return Decision.none();
   567→    }

   576→     *  （微博真机：>40 节点把真角落键挡在门外），只要无滚动/无输入框且

   601→    public static boolean isAdActivityClass(String cls) {
   602→        if (cls == null || cls.length() < 6) return false;
   603→        String c = cls.toLowerCase();
   604→        if (c.contains("qq.e.ads") || c.contains("gms.ads") || c.contains("bytedance.sdk")
   605→                || c.contains(".ad.activity") || c.contains(".ads.activity")
