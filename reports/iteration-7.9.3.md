### S2~S7 · 8 项场景行为

- **内容延迟加载**：帧1 未加载零出手 → 帧2 跳过键出现即出手（事件驱动等价表达）。
- **关闭按钮延迟出现**：videoLike 画像 / 20s 观察窗 / arm-hint 免杀链（>12s 露头按钮可等到）。
- **候选消失**：DETECTED → READY → 出手（VERIFYING）→ 两轮零确认（≥350ms 独立两轮）→ SUCCESS 不可逆 → 2.2s 冷却闸。
- **广告与反馈面板切换**：面板文案零跳过候选；FEEDBACK 态不对原广告补刀；面板收起 → SUCCESS 不恢复原任务；冷却期内残留面板候选不开新任务。
- **页面内部导航**：同窗身份零出手；聊天窗特征齐全零出手；LauncherUI 不进 feed 扫描（窗级门）。
- **窗口切换**：有出手 → SUCCESS 落账；零出手 → CANCELLED（不诬为成功）；验证中被打断 → 终局。
- **视频开屏画像调度契约**：videoLike 四因子 / 观察窗双档 / 轮询节奏（active 1.5s、终态 3s 降频）/ 白点节流 / 每 3 针全量复扫 / 预算刷新=新文本键。
- **无障碍事件触发**：服务侧调度——纯 JVM 以「事件到达前后两次扫描行为差」等价表达（诚实口径，记录于 test_matrix）。

### S8 · 订阅七分类真实计数器（生产实现首次纳入 JVM 测试面）

## 3. 测试编写过程中的诚实记录（不掩盖）

1. custom-draw 2 节点树角落图标实际触发了 corner_image_skip 出手——**审读源码确认为设计行为**（「树极简兜底」：极简窗 + 角落小钮 = 广告形态），非引擎 bug。改为三态断言。
2. videoLike 的 SDK 指纹路径纯函数仍有 streak≥3 前置（v7.9.0「streak 无条件计数」修复在服务侧豁免窗计数——纯函数前置保留）；pollDue / taskAllowsNew 语义与直觉相反处按真实语义断言（lastPollAt=0 非 null；taskEndedAt<=0 表示无任务历史 = 允许开新任务）。

## 4. 生产代码改动（仅测试钩子）

SubscriptionManager 新增 `primeForJvm()`（只加载内置订阅——与 ensureLoaded 第一段完全相同）与 `subStatSnapshot()`（七计数器快照，与 stateJson 的 subStat 段同源）。生产永不调用；幂等闸不动；remote 保持 null 基线。
