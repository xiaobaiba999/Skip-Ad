## 0. 用户实锤（第十四轮原话）

> 依旧不行，还有好多其他 app 的开屏都跳不了。开屏按钮跳过不是每个都带倒计时，
> 不是每次每个按钮都是一个位置。app 内的插入的广告也是，它们几乎都带有广告
> 两个字，扫描日志继续实现继续优化。

三条线索拆开就是三组死因：

| 用户线索 | 引擎侧死因 |
| --- | --- |
| 开屏按钮跳过不是每个都带倒计时 | ① 倒计时数字与「跳过」文案分属两个节点 → `parseCountdown(label)=0` → 首击立即出手白点；② 门控只在 `clickAttempts>=1` 才生效——首击永远提前出手 |
| 不是每次每个按钮都是一个位置 | ③ 图片跳过键（无字可点控件）在左/右缘【中部】——旧角落几何只认顶 14%/底 18% 两带，中部零收集 |
| app 内的插入的广告几乎都带有广告两个字 | ④ 名单外 App 的插入广告零覆盖：信息流两段式只在 20 款名单内、开屏阶梯 12s 窗外零动作、弹窗路径只认 Dialog 窗类——宿主窗内插层三路全漏 |

## 1. 开屏倒计时解耦（死因①②）

### 1.1 死因链重建（以 5s 穿山甲倒计时为例）

```
「跳过」文案节点（无数字） ──parseCountdown=0──→ 首击 0ms 出手（白点）
  ↓ 点击冷却 ~1.6s + 人手复验节奏
第二击 ~1.6s（白点）→ 第三击 ~3.2s（白点，倒计时还剩 2s）
  ↓ MAX_CLICKS_PER_WIN=3 耐心预算烧完
🤲 优雅收手 → 用户干看广告走完 → 「好多其他 app 的开屏都跳不了」
```

倒计时数字在【兄弟节点】（`5` 独立 TextView）里——旧引擎只解析命中键自身文案。

### 1.2 根治：兄弟节点倒计时双接入

- **walk 路径**：visit 收集独立数字候选（`standaloneCountdownSeconds`：纯「3/5s/3秒/5 S」小形态；「跳过3/1/3/16/3秒后」一律拒）→ `ScanFind.cdDigits`（≤6 条）→ walk 尾部 `resolveCdDigits`：倒计时区（顶 35%/底 25%）或任一跳过候选近旁（|Δcy|≤25% 屏高）→ 并入 `f.countdownN`
- **规则路径**：`RuleEngine.windowCountdownHint`（200 节点预算 DFS + 命中键近旁过滤）——`cdHit==0` 时补查，门控交 `countdownWait`
- **门控第 0 击起全次生效**：`countdownWait` 旧 `clickAttempts>=1` 条件删除，改纯函数 `gateCountdown(cdN, anchorAt, now)`（AdDecisionCore）从第 0 击起门控到「将尽」（`COUNTDOWN_EXTRA_MS=120` 提前量 + `scheduleGateOpenScan` 开闸精确针保持）
- **装饰数字逃生**：`decorativeCountdown`（锚点 1.6s 未刷新——真倒计时每秒跳数字重置锚点）对任何击数都放行（含窗内早见晚点：数字早于命中键出现、锚点已陈旧的场景）

5s 倒计时新链路：`0ms 发现「跳过」+兄弟「5」→ 门控 → 4.88s 开闸精确针 → 一击命中`（0 白点）。

## 2. 开屏位置解耦（死因③）

### 2.1 死因：角落几何只认顶/底两带

```
isCornerControl: topZone(b[1] ≤ 14% H) 或 bottomZone(cy ≥ 82% H)，且贴左/右缘
                 → 左/右缘中部（y 20%~80%）无字小可点控件 = 永远不是候选
真机：部分应用跳过键就是右侧中部图片键（用户原话「不是每次每个按钮都是一个位置」）
```

### 2.2 根治：中部边带候选（strongOnly 分层门控）

- `isMidEdgeControl`：贴左/右缘（≥72%/≤28% 宽）· **任意高度** · 24px~35% 宽 × 20% 高（尺寸门与角落同源）；已过角落几何的归角落（原门控语义不动）
- `CornerCand.strongOnly`（新字段）：中部候选【仅强广告形态】（热区/角标/SDK 窗/学习窗）可出手——**树极简 ≤60 兜底不适用**（FAB/普通悬浮钮误点防线，宁漏勿误红线不放松）
- L4 逐候选分层门控：从第 `clickAttempts` 个起取首个过闸候选（无 strongOnly 候选时与旧「第 N 击第 N 候选」**逐字等价**——回归零风险）
- `learnableSkipShape` 同步收编中部边带（手势候选可学习可代点）

## 3. 插屏卫士 InterstitialGuard（死因④ · 新核心模块）

### 3.1 设计依据：用户实锤的「广告」两个字

「app 内的插入的广告也是，**它们几乎都带有广告两个字**」——这不是吐槽是规格：
合规披露角标（广告/推广/赞助）是国法要求的标签，与 App 名单、窗口形态、SDK
指纹全都无关——插屏广告最稳定的通用指纹。角标在场 + 关闭钮在场 = 插屏签名。

### 3.2 五道闸（宁漏勿误红线不变）

| 闸 | 判定 | 拒什么 |
| --- | --- | --- |
| 闸⓪ 角标在场（必过） | `FeedAdGuard.isDisclosureBadge`：角标词精确等值或角标词+纯符号尾（广告×/广告·）· ≤35% 屏宽 × ≤8% 屏高 | 角标不在场绝不出手（普通页面零命中）；角标自身绝不点击（点角标=点进广告主体） |
| 闸① 关闭语义 | `INTER_CLOSE_WORDS` 精确等值（绝不 contains）：×/✕/✖/╳/⨯ > 关闭/关闭广告/关闭此广告 > 跳过/跳过广告/跳过此广告/跳過/跳過廣告/Skip > 知道了/我知道了/close（数组序即优先级） | 「进入广告/查看详情/立即下载」类营销文案；拉丁 X（正文/昵称误而险）；「不感兴趣」（feed P2 领地） |
| 闸② 关闭形态 | ≤30% 屏宽 × ≤12% 屏高（屏幕未知 324×144px 兜底） | 广告主体大图/大容器（几何兜底——绝不点广告本体） |
| 闸③ 近旁/带位 | 与角标 \|Δcy\|≤35% 屏高（同排铁证）或关闭钮在顶带（cy≤30%）/底带（cy≥70%） | 远距「关闭」绝不裸点（普通页面关闭按钮零误触面） |
| 闸④ 窗不滚动 | 服务侧 walk 判定 `scrollPresent` 传入 | 可滚动窗是信息流/正文页——归两段式与开屏阶梯（双重出手防线） |

### 3.3 李跳跳方法论主路径（与 v7.2 feed 主路径同方法论）

`findAccessibilityNodeInfosByText` 原生 C++ 直查（角标词 + 关闭词一把直查 ·
预算无关——深树插层也查得到）→ 候选交语义+形态+近旁闸逐个判定；walk 只取
滚动标记（闸④），不做候选收集。宁漏勿误红线与 DFS 路径完全一致。

### 3.4 服务侧薄接线（AdSkipService.maybeInterstitialScan）

- 钩子：窗切换（TYPE_WINDOW_STATE_CHANGED）+ 内容变化（开屏窗/弹窗窗都不在期的 TYPE_WINDOW_CONTENT_CHANGED——插层滑动入场正是内容变化源）
- 节流：2.5s 包级（INTER_SCAN_THROTTLE_MS——与空闲巡检同节奏）
- 排除：feed 名单 20 款（两段式领地）· armed 指纹窗（P2 收菜单优先）· 聊天主界面/小程序容器零扫描红线（与 feed 同源门）
- 出手：`executeInterstitial` 构造 Decision（reason=`inter_close`）走既有 `execute()`——用户让路/耐心预算/F·H 多点防线/人手手势派发/**通用边界终闸**（×/关闭/跳过族全在「关闭方向」语义面内）全量免费复用；记账 `stats.feed` 档（App 内广告关闭口径——报告饼图第 5 档）

### 3.5 决策阶梯 L1.5（角标在场关闭 · 任意位置）

开屏窗期内 walk 的 `foundClose + adBadge + 广告形态树`（≤150 节点 · 无滚动 ·
无输入框 · 非长文本）→ 任意位置出手（reason=`badge_close`）。旧 L1.6 的顶部
35% 位置闸把插屏右下/中部 × 全灭——**角标成为第二证据替换位置证据**；
无角标时 L1.6 原语义保持（顶部 × 照收）。

## 4. 扫描日志数据闭环（「扫描日志继续实现继续优化」）

- 插屏未命中诊断 `logInterMiss`（30s 包级节流）：「🔍 插屏未命中（pkg · 窗类）：角标/关闭钮未同场过闸（词命中样本：label@(cx%,cy%)——均未过闸）——上传日志可帮我们补规则」

- 三通道未命中诊断（开屏/弹窗/信息流/插屏）全部随一日三次自动日志上传

## 8. 红线复核（宁漏勿误 · 不乱点 · 不对抗用户）

- 插屏卫士只点关闭钮自身 bounds（绝不广告主体、绝不角标）；角标只在场作证据
- 中部边带候选仅强广告形态可出手（FAB/悬浮钮防线）；树极简兜底不适用
- 可滚动窗（信息流/正文页）插屏路零参与（两段式领地）；feed 名单 20 款排除
- L1.5 角标关闭须广告形态树（无滚动/无输入框/非长文本 ≤150 节点）
- execute() 全防线复用：用户让路（4s 让路红线）、耐心预算（3 击优雅收手）、F·H 多点防线、通用边界终闸（语义/场景/形态三断言）
- 零扫描场景（设置/输入法/锁屏/密码/短信/相机/守护名单/小程序/聊天主界面）上游过滤保持
