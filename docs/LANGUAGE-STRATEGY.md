# 语言策略定版报告（LANGUAGE STRATEGY · v5.6.0）

> 结论先行：**不重写。Java 保持引擎；「Java 管设备，TypeScript 管规则，脚本管流水线」定版。**
> 同类拦截开屏广告软件（GKD 等）主流用 Kotlin 的原因与本项目的选择如下。

## 一、为什么同类软件主流用 Kotlin

1. **Android 官方语言惯性**：现代安卓项目默认 Kotlin 起步，新项目零迁移成本；
2. **协程与生命周期域**：GKD 的无障碍服务/悬浮窗/订阅刷新用协程组织异步，写起来顺；
3. **生态位**：GKD 同时用 **TypeScript 写全部订阅规则 DSL**（`@gkd-kit/api` + `@gkd-kit/subscription`）——Kotlin 只占 APK 那一层。

也就是说：**Kotlin 是「新项目的默认」，不是「无障碍引擎的必需」**。

## 二、本项目为什么是多语言——以及实测后怎么定版

本项目历史包袱：Web 演示（TS）→ 安卓 APK（Java）→ 规则台（TS）→ CI 脚本（bun/TS/MJS）多种并存，GitHub 语言栏一度显示 7 种。

**基准测试（同机同轮 · 9 轮取 min-of-9 / 中位数 · 2026-11-18）**

| 维度 | Java 8（现状引擎） | Kotlin 2.0.21 | JS (V8) | Python 3.12 |
| --- | --- | --- | --- | --- |
| 稳态匹配（优化写法） | 968 ns/树 | 904 ns/树 | 484 ns/树 | 5,575 ns/树 |
| 进程冷启动 | 55.4 ms | **77.9 ms (+40.7%)** | 31.5 ms | 30.2 ms |
| 常驻内存 | 90.4 MB | **94.7 MB (+4.3MB)** | 58.6 MB | 12.9 MB |
| kotlin-stdlib | **0** | **1.75 MB**（APK 292KB→约 2MB，≈7×） | — | — |
| 重写范围 | — | **11,253 行 + 475 断言重验** | — | — |

校验和四语言逐位一致（`sel_sink=731 · hits=20000 · sink=485562`）——测的是语言，不是算法差异。

**定版裁决：**

- **Java（引擎，保持）**：稳态匹配与 Kotlin 持平（±7% JIT 区间）；冷启动反而快 40%；零运行时依赖（APK 296KB vs Kotlin 至少 ~2MB——本项目核心卖点之一就是体积小一个数量级）；d8/ECJ 工具链已在 CI 全绿；
- **Kotlin（重写否决）**：无性能收益、+4.3MB 内存、+1.75MB stdlib、11,253 行重写高风险零回报——**「为什么用 Kotlin」的答案对已用 Java 跑了 22 轮全绿矩阵的项目不成立**；
- **TypeScript（规则台/CI）**：与 GKD 订阅生态同构（`subscription-template` 全家都是 TS），保留；
- **JavaScript（WebView 壳 UI）**：V8 冷启动 31.5ms、稳态 484ns 最快——壳层最优解，保留；
- **治理**：删除 `android/` 实验性死代码（com.skipad 重复实现从未进发布物）+ `.gitattributes` linguist 标记（测试报告/构建产物/下载物不计语言栏）→ 语言栏收敛为产品语言。

## 三、热路径优化（零语义变化 · 4.9×）

`String.matches` 每调用隐式 `Pattern.compile`（含锁+分配）→ 类加载期一次预编译；`row[j].toLowerCase()` 每次分配新串 → 并行小写表；`TEXT_EXACT` 数组线性扫 → `HashSet` 等值查询。线性写法 4,748 ns/树 → 优化写法 968 ns/树（**4.9×**），1048 项 JVM 断言全绿零回归。

## 四、多语言不是问题，失控才是

定版后的语言分工（每层都是该场景最优解）：

| 层 | 语言 | 理由 |
| --- | --- | --- |
| 无障碍引擎（`android-app/src`） | Java 8 | 零依赖、冷启动快、工具链已验证 |
| 壳 UI（`assets/www`） | JS | V8 启动最快、无桥开销 |
| 规则台/CI/发布脚本 | TypeScript | 与 GKD 订阅生态同构 |
| 数据/报告 | JSON/JSON5 | GKD 兼容格式 |
