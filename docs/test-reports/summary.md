**喜马拉雅专案 v2（无倒计时 + 跳过广告 + 翻转手机 + 链式二跳）**
- v3.1.0（R1 复测）：翻转触发（1600ms）抢先于引擎节奏 → 跳转发生（用户实测「还是跳转不了」）
- v3.2.0 修复链：R3 陀螺仪诱导直断（847ms，识别「翻转手机」文案 → 0.8s 无真跳过键 → 返回键温和直断）→ R4+ 二跳回弹兜底 → R6+ 预拦截（34ms，广告未及呈现，0ms 可见）
- 双保险说明：无障碍服务无法冻结应用进程内的传感器监听（Android 沙箱边界），故采用「极速代点抢在翻转前 + 直断 + 回弹兜底」三层防线
